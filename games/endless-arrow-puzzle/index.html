About the game

Find the way out.

Every arrow wants to escape, but choosing the wrong one can leave its path blocked.

Endless Arrows is a mobile logic puzzle where the goal is to remove every arrow from the board.

Each arrow can escape only in its facing direction. Some have a clear route immediately, while others are blocked by pieces that must be removed first.

Work out the correct order, free the arrows and clear the entire puzzle.
