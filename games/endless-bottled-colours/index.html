About the game

Sort, organise and solve.

Turn a collection of mixed bottles into an organised set of matching colours.

Endless Bottled Colours is a relaxing mobile colour-sorting puzzle.

Move colours between bottles and work out the correct sequence of moves until each bottle contains only matching colours.

What begins as a simple sorting challenge becomes more demanding as the number of bottles, colours and possible moves increases.
